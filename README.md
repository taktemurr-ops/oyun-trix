# Triks

Beş sözleşme, tek krallık: cezadan kaç, dizmede ilk bitir! Yapay zekâ rakiplere ve ortağa karşı; çevrimiçi masada boş koltuklara bot oturur, kopan oyuncunun yerine bot geçer; her bölüm kazanılabilir olduğu denetlenmiş bir el; 100.000 bölüm. Kart Oyunları merkez uygulamasının oyunu; ortak motor: kart-motoru.
